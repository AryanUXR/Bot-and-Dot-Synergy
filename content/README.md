# Content — Writing Rules and Templates

Every piece of copy that goes into a prototype must pass through these files before it reaches a Lovable prompt.

| File | When to read |
|------|-------------|
| `anti-slop-rules.md` | Before writing ANY prototype copy — personas, dot descriptions, hero text, taglines |
| `persona-writing-guide.md` | When drafting personas.ts content |
| `dot-data-guide.md` | When drafting dot data (names, descriptions, offers) |
| `use-case-brief-template.md` | When parsing a new use case brief |
