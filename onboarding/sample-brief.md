# Sample brief for a dry run

Use this when the user has no infographic yet. It creates nothing on any platform.

- **Programme:** Teal Dots, Coimbatore (fictional example)
- **Problem:** small-town weavers can't find buyers, designers or loans, and buyers can't find weavers.
- **Seekers:** a handloom weaver looking for orders; a young designer looking for weavers.
- **Providers:** fictional cooperatives, a loom repair worker, a design school, a bank branch, a fair-trade buyer.
- **Language:** Tamil, with English for menus.
- **Bot name:** pick one with the user.

A dry run produces:
- a filled `content/use-case-brief-template.md`;
- three personas, following `content/persona-writing-guide.md`;
- ten fictional dots, following `content/dot-data-guide.md`.

Check all three against `non-negotiables.md`.
