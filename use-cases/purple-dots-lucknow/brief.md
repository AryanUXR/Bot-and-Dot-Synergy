# Purple Dots Lucknow: map brief

**Sources:** the Purple Dots AI infographic, and Aryan's bot "Divya 2.0 Purple Dots Lucknow" (Lovable `3b35a5d0-f9ab-416c-8bd9-d1c0cb65ce4f`, Raya agent `6bc38769`, which uses a knowledge base and never names providers). This build is the dot map only.

- **Problem:** PwDs and nearby jobs, services and support can't see each other. Waiting for a device or training costs income.
- **Before:** "I wish someone would look at my skills before my disability."
- **After:** "Glad to know there are so many opportunities built around inclusion."
- **Promise:** help employers and service providers find PwDs within 5 km, in hours.

```
## Programme       Purple Dots Lucknow
## Colour          Purple #7B5EA7, dark #3F2D6B (the bot uses #7B5EA7 → #534AB7)
## Geography       Lucknow city (Aliganj, Husainabad, Rajajipuram, Alambagh, Chinhat, Gomti Nagar...) plus Basti town for Deepak.
                   Basti is about 200 km away, so it stays outside the opening view.
## Seekers         PwDs (low vision, hearing loss, locomotor, progressive conditions) looking for devices, certificates,
                   rehabilitation, training and jobs
## Providers       UDID and certificate help · assistive devices · rehabilitation and therapy · skilling ·
                   inclusive employers and placement · schemes and pensions · assistive-tech learning · NGOs and peer groups
## Sectors (9)     the eight provider types above, plus PwD Requests
## Map "You"       Gaurav, Aliganj (the bot's featured persona)
## Data            fictional; real localities and public scheme names; no phone numbers
## Bot             already built by Aryan; personas in its src/data/personas.ts
```

**Language rule for the map:**
- Use person-first, respectful terms: "person with low vision", "hearing loss", "uses crutches".
- Use "divyang" only in scheme names.
- Never use words like "handicapped", "suffering from", "victim" or "confined to a wheelchair".
