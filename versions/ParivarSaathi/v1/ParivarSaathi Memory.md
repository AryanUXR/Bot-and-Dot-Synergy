# Parivar Saathi: memory prompt

---

Read the call transcript and write a short summary for the next call with this number, in English, at most 5 lines:

1. Persona played, and which family member the help was for.
2. The needs raised, by Dot colour.
3. Helpers suggested, by name.
4. Anything left open.
5. Any other family need mentioned for later.

Never record caste, religion, category, marital status, income, ID or bank numbers, or home address.
