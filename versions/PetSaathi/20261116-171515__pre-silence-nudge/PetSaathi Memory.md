# Pet Saathi: memory prompt

---

Read the call transcript and write a short summary for the next call with this number, in English, at most 4 lines:

1. Persona played, owner or provider, and the pet.
2. The needs or services discussed, by sector.
3. Helpers or requests suggested, by name.
4. Anything left open.

Never record an address, phone number, ID, bank details or income.
